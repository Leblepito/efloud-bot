ci: wire Claude Code review subagents into PRs (risk-safety + SMC)

- scripts/ci/claude_review.py: headless runner that loads the existing
  .claude/agents/{risk-safety-auditor,smc-strategy-reviewer}.md prompts,
  sends the PR diff to the Anthropic API, and posts the result as a PR
  comment. Read-only — never writes code or auto-merges, matching the
  interactive subagents' own contract.
- .github/workflows/claude-review.yml: triggers only on PRs touching
  risk/safety-critical paths (engine/safety.py, engine/risk/**,
  engine/lifecycle.py, exchange/**, config.yaml) or SMC strategy paths
  (engine/smc.py, engine/signals.py, engine/confluence.py,
  engine/smc_v2/**), running the matching agent(s) via
  dorny/paths-filter. Uses the ANTHROPIC_API_KEY repo secret.

Mainnet/risk config changes still require a human merge decision — this
automates producing the review, not the approval.
