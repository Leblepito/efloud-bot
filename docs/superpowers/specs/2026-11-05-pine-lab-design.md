## 1. Hedef

Bir **lab** Pine ailesi: tüm toggle'lar kapalıyken canlı botun **amaçlanan** mantığını birebir üretir (baseline); her iyileştirme bağımsız bir toggle'dır; Strategy Tester'da baseline ile karşılaştırılır; parity harness baseline'ın canlı Python'la eşleştiğini kanıtlar. Kazanan toggle'lar sonraki spec'te default-OFF olarak Python'a taşınır.

Kapsam dışı: yatay konsolidasyon range dedektörü, Mitigation Block, Python tarafı değişiklikler (B1/B2 dahil), limit emir yolu.

## 4. Baseline algoritması (tüm toggle'lar kapalı)

Tüm hesap `barstate.isconfirmed` altında, bar kapanışında. Canlı fetcher forming bar'ı düşürür (`backend/tests/test_fetch_ohlcv_forming_bar.py`) → veri görünümü aynı. Python'daki hatalar B1/B2 **kopyalanmaz**; harness bunları ayrı sütunda raporlar (§7.1).

### 4.1 Yapı motoru (chart TF)

LuxAlgo Pine mantığı: `leg(50)` swing, `leg(5)` internal, `leg(3)` equal; pivot `size` bar sonra onaylanır. Kırılım: close pivotu crossover/under eder, pivot daha önce kırılmamış → bias tersse CHoCH, aynıysa BOS; internal pivot == swing pivot ise internal kırılım sayılmaz. OB: `[pivot.bar, kırılım−1]` içinde parsedLow argmin (BULL) / parsedHigh argmax (BEAR); range ≥ 2×ATR(200) mumda high/low yer değişir. Mitigation HIGHLOW: fitil uzak kenarı geçince havuzdan düşer. FVG: `low > high[2] and close[1] > high[2] and delta% > auto-eşik`; EQH/EQL `|Δ| < 0.1×ATR200`; trailing top/bottom → dealing range, EQ = orta nokta, eq bandı [0.475, 0.525].

`liveWindowBars`: OB/FVG/pivot/equal havuzları ve FVG kümülatif eşiği son 750 bara kırpılır → Python'ın 750-bar penceresiyle aynı geçmiş.

### 4.2 HTF bias

`request.security(biasTf, f_swingTrend(htfSwingLen)[1], lookahead=barmerge.lookahead_on)` (`biasTf` default 12h; T1 kapalıyken baseline HTF budur) — `[1]` + lookahead_on = mevcut repaint-free desen (PINE_SPEC §15). BULL/BEAR/UNDEF; UNDEF → aday yok.

### 4.3 Aday üretimi (her bar)

Son `recencyBars` içindeki her kırılım: yön == bias → kind izinli → OB var, mitigate değil → P/D: LONG `ob.top ≤ EQ`, SHORT `ob.bot ≥ EQ` → tag ≥ minConfluence (SWING_OB swing kırılımda otomatik; OTE = OB ∩ [0.618, 0.786] retrace bandı; EQ = OB ∩ eq bandı; FVG = OB'den sonra aynı yönlü aktif FVG ile çakışma; SWEEP = OB ucu önceki swing pivotunu geçmiş) → emit kapıları: yakın kenar ≤ maxZoneDistAtr, aşım ≤ maxOvershootAtr (ATR14 Wilder) → dedup (yön, kırılım barı) → aktif aday ≤ maxPending. EXPIRED/CONFIRMED sonrası pencere içindeki aynı kırılım yeniden emit edilir (F7 — baseline sadakati).

### 4.4 State machine (aday başına)

```
AWAITING_PULLBACK ─close∈zone─► IN_ZONE ─close∉zone─► AWAITING_REENTRY ─close∈zone─► IN_ZONE
IN_ZONE: kırılımdan beri TÜM barlarda engulfing + close∈zone ara (F6 baseline)
         bulundu ve Po3 manipulation değil → CONFIRMED, entry = engulfing close, MARKET
bars_waited > timeoutBars → EXPIRED
```

Engulfing: LONG prior bearish, cur bullish, `cur_open ≤ prior_close and cur_close ≥ prior_open`; SHORT ayna. Po3: [po3AccStart, po3AccEnd) UTC birikim kutusu; kutu süpürüldü, displacement (`body ≥ disp_mult × ref`) yok → manipulation → onay bloklanır, aday bekler; UNDEFINED bloklamaz.

### 4.5 SL / TP (CONFIRMED barında)

SL: LONG `ob.bot − slBuffer×ATR14`; mesafe < minSlAtr×ATR → `entry − minSlAtr×ATR`; > maxSlAtr×ATR → setup reddedilir (aday tüketilir, işlem yok). SHORT ayna.

TP adayları (LONG): karşı aktif OB `bot`, karşı aktif FVG `bot`, EQH `price_b − 0.15R`, swing high pivotlar `− 0.15R`, EQ, trailing top `− 0.15R`; sıralı. TP1 = `≥ minRr×R` karşılayan en yakın; aday var ama hiçbiri karşılamıyor → red; hiç aday yok → `entry + minRr×R` projeksiyon. TP2 = TP1 ötesindeki sonraki aday; yoksa trailing range fib ext {1.272, 1.618, 2.618} TP1 ötesindeki ilki; o da yoksa null.

## 6. Strategy / indicator tail, kazanma kriteri

### 6.1 Strategy tail

`strategy("EFloud Lab Strategy", overlay=true, initial_capital=1363, commission_type=strategy.commission.percent, commission_value=0.04, slippage=1, pyramiding=1, process_orders_on_close=true, max_lines_count=500, max_labels_count=500, max_boxes_count=500)`.

Sizing `qty = marginUsd×leverage/entry`. Giriş: baseline/T5 → `strategy.entry` market CONFIRMED barında; T3 → limit (§5). Sembol başına 1 açık pozisyon; pozisyon açıkken adaylar ilerler, emir vermez. Çıkış: `strategy.exit` SL+TP1; TP1 dolunca TP2 varsa `tp1ClosePct` kapat + SL→entry (BE), kalan TP2; TP2 yoksa %100. `time − entryTime ≥ maxHoldHours` → `strategy.close`. `comment = variantLabel + "|trig=<ts>|sl=|tp1=|tp2="` → trade CSV eşleme ve skor için.

Modellenmeyen: günlük/haftalık/3-kayıp breaker'lar, %1 entry drift (close-fill'de 0), funding, çoklu sembol margin etkileşimi.

### 6.2 Indicator tail

Çizim: aktif OB kutuları, bekleyen aday zone'ları (state rengi), T3'te leg + 0.618/0.705/0.786 çizgileri, CONFIRMED'de entry/SL/TP1/TP2 + label; havuz ≤ 200 nesne. Dashboard: `variantLabel` (toggle'lardan otomatik, örn `B|T1=4h/hard+12h|T3|T4`), bias, aday sayısı/state'ler, son 20 düşme nedeni. Alert: `alert()` JSON `{symbol, dir, entry, sl, tp1, tp2, variant, trigger_bar}`, `alert.freq_once_per_bar_close`; `alertcondition` yok.

### 6.3 Kazanma kriteri

Veri: 10 canlı sembol × chart TF 15m, TV planının verdiği maksimum bar (hedef ≥ 3 ay). Her varyant → Strategy Tester trade CSV → `pine_lab_parity.py score`. Toggle kazanır ancak hepsi sağlanırsa: (1) toplam n ≥ 50, (2) toplam NET R > baseline, (3) ortalama NET R/işlem > baseline, (4) max DD(R) ≤ baseline×1.2. Aksi → default KAPALI.
