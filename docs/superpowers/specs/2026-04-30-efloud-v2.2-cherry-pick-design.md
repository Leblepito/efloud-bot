## Wiring stratejisi

`CustomRiskCalculator` opt-in flag ile entegre edilir:

```yaml
# config.yaml veya configs/config.phase2_micro.yaml içinde:
risk:
  # MEVCUT (default davranış, dokunulmuyor):
  risk_per_trade_pct: 0.5
  min_rr: 1.8

  # YENİ — OPT-IN (default kapalı):
  position_size_calculation: legacy   # "legacy" | "reverse_from_risk"
  max_loss_per_trade_usdt: 10
  target_stop_distance_pct: 5
```

`safe_orchestrator.py`'de tek `if/else`:

```python
if cfg["risk"].get("position_size_calculation") == "reverse_from_risk":
    calc = CustomRiskCalculator(
        max_loss_usdt=cfg["risk"]["max_loss_per_trade_usdt"],
        leverage=cfg["exchange"].get("leverage", 1),
        target_stop_pct=cfg["risk"]["target_stop_distance_pct"] / 100.0,
    )
    size = calc.calculate_position_size(actual_balance)
else:
    size = calc_position_size(actual_balance, ...)  # mevcut davranış
```

`validate_config()` davranışı:
- Mode kapalı (`legacy`) → leverage/margin/mainnet kombinasyonu kontrol eder, başka şey yapmaz
- Mode açık (`reverse_from_risk`) → ek olarak min notional ($10) ve stop distance sanity check yapar
